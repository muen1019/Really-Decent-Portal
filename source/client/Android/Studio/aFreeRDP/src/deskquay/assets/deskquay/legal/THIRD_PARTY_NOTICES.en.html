Unicode CLDR provenance

The 500 ordered (IANA type, Windows name, territory) entries in the compiled WindowsZones table match the CLDR XML at commit c33a1f0a23e3b676b406345fe0b42c130defc51d, including its otherVersion and typeVersion values. The original generator fetched a moving branch, so the paired snapshot is the verified source equivalent. FreeRDP generation change · CLDR WindowsZones data

ARM64 runtime inputs

The runtime license map pairs the 0.1.9 native compile and link inputs with their shipped libraries and notices. It covers the rebuilt FreeRDP, WinPR, Android JNI wrapper, OpenSSL, cJSON, and uriparser, plus the separately supplied SQLCipher AAR.

The Android NDK 29 compiler support archives are paired with LLVM's runtime notice, including the LLVM Exceptions. The actual CRT objects are paired with the Android NDK notice. These original notices cover the broader toolchain as well. System shared libraries are supplied by Android. Files without a clear per-file header are recorded as PER-FILE-ORIGINAL-UNCLASSIFIED and distributed with their original contents and root notices.
